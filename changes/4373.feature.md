Added `zarr.Array.scatter_reduce` (and its async counterpart
`AsyncArray.scatter_reduce`), which merges a batch of sparse coordinate
updates into an array in a single call. Duplicate coordinates within the
batch are first combined with each other using the requested op
(`op="add"`, `"min"` or `"max"`) and then with the stored values, so every
update is applied exactly once regardless of ordering. Updates are grouped
by chunk: each touched chunk (or shard) is read and written once per call,
no matter how many selected points fall into it. All validation
(out-of-bounds coordinates, unsafe dtype conversion, value shape mismatch)
happens before any chunk is written, so a rejected call leaves the store
untouched. Correctness is guaranteed for a single call only; concurrent
writers to the same chunk are not coordinated.
