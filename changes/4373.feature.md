Added Array.sum, Array.mean and Array.variance (and their AsyncArray
counterparts): memory-bounded reductions over one or more axes, with
keepdims, an optional accumulator dtype, a caller-provided out array,
and nan_policy='propagate'/'omit' handling. Data is processed one stored
block (shard, or chunk when unsharded) at a time, so the working set scales
with the block size rather than the total number of elements. Per-block
count/mean/M2 statistics are merged across blocks with the numerically
stable pairwise update of Chan et al., so the variance stays accurate when
the mean is large relative to the spread. Unwritten blocks count as
fill_value observations; empty reductions yield 0 for sum and NaN for
mean/variance, and variance supports ddof.
