Add an ``erase`` parameter to ``zarr.Array.resize`` and
``zarr.AsyncArray.resize``. When ``erase=True``, shrinking an array not only
deletes the chunks that fall entirely outside the new shape, but also
overwrites the out-of-bounds cells of retained boundary chunks with the
array's fill value before the new shape is committed. Truncated data can
therefore no longer reappear when the array is subsequently grown again.
