Add zarr.Array.scatter (and the AsyncArray equivalent) together with
vindex.add / vindex.min / vindex.max helpers for batched sparse updates with
duplicate coordinates. Values are combined with existing data using "add",
"min", or "max" aggregation (in the style of numpy.ufunc.at), so repeated
coordinates within one call are merged rather than overwritten. All
coordinates and value dtypes are validated before any chunk is written, and
each touched chunk (or shard) is read and written at most once per call.
