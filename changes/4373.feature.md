Added `Array.get_window` and `AsyncArray.get_window`, a read-only windowed
read API for convolution-style access patterns. The window is given by an
`origin` and a `shape`; it may extend beyond the array bounds, and the
result always has exactly the requested shape (coordinates are never clipped).
Out-of-bounds positions are resolved per axis with `mode="constant"`
(filled with the array's fill value or a custom `constant_value` cast to the
array's dtype), `mode="reflect"` (mirrored without repeating the edge
element), or `mode="wrap"` (periodic repetition). Only unit-stride windows
are supported. Reads only touch chunks that intersect source data actually
required by the window, and source regions that repeat (e.g. multiple wrap
periods) are fetched once and reused.
