Added an offline shard-compaction entry point, `zarr.codecs.sharding.compact_shard`
(and the in-memory `compact_shard_bytes`). It rewrites a shard whose data section
contains unreferenced gaps so that every chunk payload still referenced by the shard
index is packed contiguously, updating the index offsets without decoding or
recompressing any chunk bytes. The index checksum and every referenced byte range
are validated first: out-of-bounds ranges and partially overlapping chunks raise
`ShardIndexCorruptionError` naming the inner-chunk coordinates, identical ranges
shared by multiple chunks are stored once, and empty-chunk markers are preserved.
Both `index_location` layouts are supported, the source shard is only read, and
the compacted shard is published to a separate target path atomically.
