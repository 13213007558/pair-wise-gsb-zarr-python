Add ``zarr.experimental.VirtualConcatArray``, a read-only view that concatenates
several Zarr arrays (e.g. one array per month, possibly in different stores) along
a single axis without copying any data.  The view supports basic and orthogonal
selections across component boundaries, serializes to a credential-free
configuration, and raises ``ConcatViewInvalidError`` if a component changes shape
after the view was created.
