Added `zarr.integrity` for saveable per-chunk integrity manifests.

`IntegrityManifest` records dtype, logical shape, and a SHA-256 digest of the
decoded valid elements for each logical chunk (boundary padding excluded),
along with whether each chunk was originally an implicit fill. Digests are
encoding-independent: compressors and shard placement do not affect them,
and NaN payloads, byte order, and signed zero follow fixed canonical rules.
`verify_manifest` can verify the whole array or only chunks intersecting a
selection and reports changed data, missing chunks, and incompatible metadata
without attempting repairs.
